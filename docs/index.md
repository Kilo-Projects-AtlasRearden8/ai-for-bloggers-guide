# Manual Contents

Welcome to **Blogging with Free AI**, a beginner manual from Asdale Dynamics, LLC.

This guide teaches you how to start and run a blog using only free AI tools, in plain English and step by step.

## Sections

- [01 Getting Started](01-getting-started.md) — pick a platform, choose free AI tools, learn the privacy rule
- [02 Topic Ideas](02-topic-ideas.md) — brainstorm what to write about with free AI
- [03 Outlines](03-outlines.md) — turn a topic into a simple outline
- [04 Drafting](04-drafting.md) — write your post with AI help
- [05 Headlines](05-headlines.md) — write honest, useful titles
- [06 Images](06-images.md) — find and make free images
- [07 Scheduling](07-scheduling.md) — publish on a simple, repeatable schedule
- [08 Repurposing](08-repurposing.md) — turn one post into many pieces of content
- [09 Privacy](09-privacy.md) — never paste personal info into AI tools
- [Printable Planner](planner.md) — a one-page planner to print and fill out by hand

## The privacy rule

**Never paste personal information into an AI tool.** Read [09 Privacy](09-privacy.md) before you write your first post.
