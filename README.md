# Blogging with Free AI: A Beginner Manual

A plain-English, step-by-step guide to writing and publishing blog posts using free AI tools.

## Who this is for

This manual is for beginners who want to start a blog without spending money on AI subscriptions. You do not need to be a coder, a designer, or a tech expert. If you can write an email, you can use this guide.

It was written by Asdale Dynamics, LLC, an Indiana company focused on beginner-friendly AI education, books, and practical tools. Learn more about Asdale Dynamics, LLC at the hub site dylanasdale.github.io.

## How to use this guide

Work through the sections in order. Each section gives you small, concrete steps. Try each step on your own blog before moving on. There is a printable planner at the end to help you track posts week by week.

## Static site

A ready-to-use HTML version of this manual lives in `site/`. Open `site/index.html` in any browser to read it offline, or print the planner page from `site/planner.html`.
